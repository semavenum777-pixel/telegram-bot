# Telegram Sticker Bot

Бот делает стикеры для Telegram:

- **картинка без подписи** → стикер 512×512;
- **картинка + подпись** («сделай аниме, фон космос, надпись "Привет"») → нейросеть меняет фото, бот добавляет надпись;
- **только текст** («кот в очках, без фона, надпись "Йо"») → нейросеть рисует стикер с нуля.

**«😊 Набор эмоций»** — из одного селфи бот делает 6 стикеров (радость, грусть, злость,
любовь, смех, удивление) с надписями и сразу складывает их в личный пак с нужными эмодзи.
Ещё есть «🎲 Удиви меня» (случайная смешная идея), «🎲 Случайный стиль», 12 стилей
(аниме, Pixar, LEGO, плюшевый, Ван Гог, зомби…), быстрые надписи «Ок / Спасибо / Ахах / Люблю»
и кнопка «📤 Поделиться паком». В названии пака указан бот — так о нём узнают друзья.

**Ещё:** аватарки в любом стиле, мемы (`/mem верх | низ`, без нейросети), работа в групповых
чатах (ответьте на фото командой `/sticker`), новогодний режим с 1 ноября по 14 января
(стили «Дед Мороз», «Снегурочка», «Свитер с оленями», «Эльф», новогодний набор стикеров и открытки;
включить или выключить вручную — переменная `NEW_YEAR_MODE=on/off`).
По адресу сайта на Vercel открывается страница-витрина бота со ссылкой на Telegram.

**«📸 Фотосессия — реалистичное фото»** — как Nano Banana: модель Google
`google/gemini-2.5-flash-image` через баланс Pollinations (`POLLINATIONS_PHOTO_MODEL`) делает
реалистичное фото с тем же лицом: пляж, Париж, деловой портрет, модная фотосессия, ретро, космонавт,
новогодняя фотосессия и т.д. Свой запрос — фото с подписью `/photo я в смокинге на красной дорожке`.
Бот перебирает несколько моделей Pollinations (Nano Banana, Qwen Image, GPT Image — как в ChatGPT,
Seedream, FLUX Kontext): какая доступна на вашем балансе, та и сработает; потом — остальные нейросети.
Под фото написано, какая нейросеть его сделала. Результат можно сразу оживить в видео.

**Личный бесплатный баланс у каждого пользователя.** Если подключена база (Upstash Redis, см. ниже),
«📸 Фотосессия» и «🎬 Оживить фото» работают на балансе Pollinations самого пользователя
(Connect User Wallets): пользователь нажимает «🔗 Подключить бесплатный баланс» или `/connect`,
входит на Pollinations через GitHub, разрешает доступ — и пользуется, пока не кончится его собственный
бесплатный лимит. `/balance` — остаток, `/disconnect` — отключить. Ваш `POLLINATIONS_KEY` при этом
на чужие фото и видео не тратится. Без базы бот, как раньше, использует общий `POLLINATIONS_KEY`.
Необязательно: `POLLINATIONS_APP_KEY` (публичный ключ `pk_...` из enter.pollinations.ai → Apps) —
тогда на экране подтверждения будет видно название вашего бота.

**«🎬 Оживить фото — живое видео»** — видео-нейросеть (Pollinations, по умолчанию `alibaba/wan-2.2-fast`)
превращает фото в 4-секундное живое видео: человек улыбается, машет, подмигивает, смеётся, танцует.
Видео можно сразу превратить в живой стикер. Кнопка появляется, только если задан `POLLINATIONS_KEY`;
генерация тратит баланс Pollinations. Для этого фото загружается в хранилище Pollinations
по неопубликованной ссылке и удаляется через 30 дней.

**«✨ Оживить»** под любым стикером делает из него анимированный видео-стикер
(покачивание, прыжки, пульс, вертушка, тряска) — без нейросети, его тоже можно добавить в пак.
Кнопка «🎞 GIF» отдаёт ту же анимацию GIF-файлом, а под присланным фото — сразу делает GIF из фото. Любая присланная гифка превращается
в живой стикер, а гифка с подписью `/mem верх | низ` — в мем-GIF.

Под каждым стикером кнопки «🔄 Ещё вариант», «✍️ Надпись» (ответьте на стикер текстом)
и «➕ В мой пак» (бот собирает личный стикерпак, ссылка — по команде `/mypack`).
Фото или готовый стикер без подписи — бот предлагает стили кнопками. Стикеры без фона
получают белую обводку, как у настоящих стикеров Telegram. Описание бота и меню команд
бот настраивает сам.

Нейросети бесплатные и перебираются по очереди. Если у одной закончился лимит или она
не ответила, бот сразу переходит к следующей (а исчерпавшую лимит пропускает 30 минут):

1. **Cloudflare Workers AI** — ~300 картинок в день, умеет менять фото. Модели FLUX.2 klein 4B,
   запасная FLUX.2 klein 9B и FLUX.1 schnell (только по тексту), лимит у них общий;
2. **Google Gemini** — умеет менять фото (если бесплатный тариф доступен для вашего ключа);
3. **Black Forest Labs** (создатели FLUX) — умеет менять фото, модель задаётся `BFL_MODEL`;
4. **Pollinations** — небольшой бесплатный баланс: FLUX и GPT Image (модель картинок OpenAI, как в ChatGPT);
5. **Kandinsky (Сбер, FusionBrain)** — рисует только по тексту.

Подключена та нейросеть, ключи которой заданы в настройках. Достаточно одной.

## Запуск (всё бесплатно, без карты)

### 1. Токен бота
Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.

### 2. Нейросеть Cloudflare (основная)
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Откройте **AI → Workers AI → Use REST API**.
3. Скопируйте **Account ID**.
4. Нажмите **Create a Workers AI API Token → Create API Token** и скопируйте токен.

### 3. Запасные нейросети (необязательно, любые из списка)
- **Gemini:** войдите в [aistudio.google.com](https://aistudio.google.com/apikey) и нажмите **Create API key**.
  Из России сайт открывается только через VPN.
- **Black Forest Labs:** зарегистрируйтесь на [dashboard.bfl.ai](https://dashboard.bfl.ai) и создайте API key.
- **Pollinations:** войдите на [enter.pollinations.ai](https://enter.pollinations.ai) через GitHub и создайте ключ `sk_...`.
- **Kandinsky:** зарегистрируйтесь на [fusionbrain.ai](https://fusionbrain.ai), откройте раздел **API**
  и создайте ключ — получите **API key** и **Secret key**.

### Платные модели со стартовым бонусом (необязательно)
Любой сервис со стандартом OpenAI Images API (OpenAI, Together AI и другие) подключается
без изменения кода — добавьте в Vercel до 5 наборов переменных:

| Переменная | Пример |
|---|---|
| `EXTRA1_URL` | `https://api.openai.com/v1` |
| `EXTRA1_KEY` | ключ сервиса |
| `EXTRA1_MODEL` | `gpt-image-1` |
| `EXTRA1_SIZE` | необязательно, например `1024x1024` |

Следующий сервис — `EXTRA2_URL`, `EXTRA2_KEY`, `EXTRA2_MODEL` и т.д. Для фото такие сервисы
пробуются сразу после Gemini и Black Forest Labs. Когда бонус закончится (ответ 402),
бот перестанет обращаться к сервису на 6 часов и будет работать на бесплатных.

### 4. Хостинг Vercel
1. Войдите на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project** → выберите репозиторий `telegram-bot` → **Import**.
3. В **Environment Variables** добавьте переменные из таблицы ниже.
4. Нажмите **Deploy**.
5. Когда деплой закончится, откройте `https://<ваш-проект>.vercel.app/setup` —
   появится «✅ Бот подключён!».

Дальше Vercel сам обновляет бота при каждом изменении в ветке `main`.
После обновлений бот сам донастраивает вебхук при первом сообщении — `/setup` открывать заново не нужно.

### 5. Дневной лимит на пользователя (необязательно)
В проекте Vercel откройте **Storage → Create Database → Upstash for Redis** (бесплатный план),
подключите базу к проекту и сделайте **Redeploy**. Переменные базы Vercel добавит сам.
По умолчанию лимит — 20 стикеров через нейросеть в день, меняется переменной `DAILY_LIMIT`.
База также защищает от повторной обработки, если Telegram прислал одно сообщение дважды.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `CF_ACCOUNT_ID` | для нейросети | Account ID из Cloudflare |
| `CF_API_TOKEN` | для нейросети | API-токен Workers AI |
| `GEMINI_API_KEY` | нет | Ключ Google Gemini — запасная нейросеть |
| `BFL_API_KEY` | нет | Ключ Black Forest Labs — запасная нейросеть |
| `POLLINATIONS_KEY` | нет | Ключ Pollinations — запасная нейросеть (FLUX и GPT Image) |
| `POLLINATIONS_APP_KEY` | нет | Публичный ключ приложения `pk_...` — название бота на экране подключения баланса |
| `POLLINATIONS_VIDEO_MODEL` | нет | Видео-модель для «Оживить фото» (по умолчанию `alibaba/wan-2.2-fast`) |
| `POLLINATIONS_PHOTO_MODELS` | нет | Модели для «Фотосессии» и `/photo` через запятую, пробуются по очереди (по умолчанию Nano Banana, Qwen Image, GPT Image, Seedream, FLUX Kontext, P-Image Edit) |
| `VIDEO_SECONDS` | нет | Длина живого видео в секундах (по умолчанию 4) |
| `FUSIONBRAIN_KEY` | нет | API key Kandinsky (FusionBrain) — только рисование по тексту |
| `FUSIONBRAIN_SECRET` | нет | Secret key Kandinsky (FusionBrain) |
| `DAILY_LIMIT` | нет | Сколько стикеров через нейросеть в день на человека (по умолчанию 20, работает с Upstash Redis) |
| `NEW_YEAR_MODE` | нет | `on` / `off` — включить или выключить новогодний режим вручную (по умолчанию сам: 1 ноября — 14 января) |
| `WEBHOOK_SECRET` | нет | Секрет для проверки запросов от Telegram (по умолчанию выводится из токена) |

Без ключей нейросетей бот всё равно работает, но только превращает картинки в стикеры.

Шрифт `fonts/DejaVuSans-Bold.ttf` — [DejaVu Fonts](https://dejavu-fonts.github.io/), свободная лицензия.
